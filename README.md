# 🌌 Cosmos & Zodiac Interactive Observatory

An interactive, multi-page front-end web application that simulates the Solar System, moon phases, celestial constellations, and daily astrological transits in real time.

## ✨ Features

- **☀️ Real-Time Solar System Simulation:** Animated orbits featuring the Sun, Mercury, Venus, Earth (with Moon), and Mars. Includes a pause/resume motion toggle and interactive celestial body inspection.
- **🌙 Lunar Calendar & Zodiac:** Dedicated secondary page tracking real-time moon phases (New Moon, Full Moon, etc.) and their passage through the astrological zodiac signs for the current month.
- **✨ Celestial Constellations:** Interactive gallery displaying mythological star patterns (Orion, Ursa Major, Cassiopeia, and more) with custom stellar maps and detailed descriptions.
- **♈ Zodiac Signs & Planetary Transits:** Daily astrological transit simulator showing where planets reside across the zodiac signs and houses, complete with detailed interpretations.
- **🎨 Space-Themed Aesthetics:** Designed with a deep black and dark purple space background, accented by neon dark pink/magenta and twinkling white typography.
- **📱 Fully Responsive:** Optimized mobile-first layout ensuring smooth navigation, touch-friendly grids, and flawless viewing on smartphones and tablets.
